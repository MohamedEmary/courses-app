# Roadmap

Current state: Express 5 + TypeScript API (`server/`) with JWT access/refresh auth, role-based access (`user`, `admin`), course CRUD, user management, avatar uploads, Zod validation, JSend responses. DB: MongoDB with `users` and `courses` collections, no relations. See `server/README.md` for the full API reference and `other/db-schema.md` for the schema diagram.

## Future Goals
